## iLovePDF Desktop 2.2.6

03/12/2025

<br/>

### Improvements

- PDF Reader: Added Layers detection feature to manage the visibility of PDF layers.
- PDF Reader: Viewer zoom has been changed to follow the mouse cursor instead of fixed coordinates.
- PDF Reader: Now document properties like zoom value or last page visited will be remembered when you reopen a document.
- PDF to Office: Improved PDF document compatibility to ensure successful results.
- Edit PDF: You can now insert blank pages directly into your PDFs from the left panel of the edit tool.
- Compress PDF: You are now advised that Recommended and Extreme compression levels remove accessibility tags from PDF documents that include accessibility features.
- Redact PDF: You can now redact any content from a selected area instead of only highlighting text and entire pages. 
- Installer: MSI installer versions for Windows now include an automatic update system.
- SSO Login: Fixed an issue where the app wasn't informing correctly when SSO access was denied or invalid.
