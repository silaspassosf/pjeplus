## iLovePDF Desktop 2.0.12

17/03/2023

<br/>

### Improvements

- Improved management of file attachments
- Longer text is displayed more clearly
- Bug fixes in the Categories view
- Reader: Smoother Reader animations
- Password message bug fixed for documents with long filename
- Improved App icon size for macOS
- Added a new background in macOS app installer
- Fixed Color Picker dialog UI for apps in dark mode
- Fixed password characters for old macOS versions
- Fixed a crash caused by searching for a page in documents with a large number of pages
- Watermark: fixed a bug that prevented input images from containing non-alphanumeric characters
- Improved the UX in the 'Try the Repair Tool' dialog
- Fixed a bug that caused attachments with long file names to have broken UI layouts
