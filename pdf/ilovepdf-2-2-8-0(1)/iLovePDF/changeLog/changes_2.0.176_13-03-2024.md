## iLovePDF Desktop 2.0.176

13/03/2024

<br/>

### Improvements

For macOS: 
- Mac users can now select print quality levels in the printer settings, including printing in draft quality to save ink.
- Minimum macOS compatibility lowered to Mojave 10.14.
- Print in greyscale now available in macOS.
- Printing disabled for macOS 10 versions due to discontinued Apple compatibility.
- Users can now select a printer tray from the macOS printer settings.

For Windows:
- Users can now deactivate the results popup for right-click tools.
- Resolved a bug where Windows notifications failed to inform about incorrect tools after processing.
- Resolved a bug that caused Windows notifications to show the incorrect tool.

Both platforms:
- Fixed a bug that allowed multiple simultaneous app update requests.
- Non-Premium users can now check remaining free tasks from their Profile Overview.
- Watermark PDF settings now cleared upon tool restart.
- Improved Watermark PDF functionality for RTL languages.
- Fixed an issue preventing printing in sizes other than A4.
- Fixed an issue causing increased CPU and GPU consumption when the app was idle.
