Juntar PDFs

Juntador simples: escolhe os arquivos, confere a ordem, gera o PDF único.

Instalar como favorito

  1. Mostre a barra de favoritos: Ctrl + Shift + B
  2. Arraste o botão abaixo para a barra de favoritos:

Juntar PDFs

Não abriu? Configure a URL manualmente como mostrado abaixo.

Modo manual

  1. Abra o arquivo D:\PjePlus\tools\juntar_pdf.html no navegador
  2. Adicione aos favoritos: Ctrl + D
  3. Escolha a barra de favoritos e salve
O favorito aponta para um arquivo do seu computador. Se você mover a pasta PjePlus de lugar, o favorito para de funcionar — basta refazer o passo 2.

Como usar

  1. Clique no favorito — abre a página do juntador.
  2. Clique em “Clique para escolher os PDFs”.
  3. Selecione vários arquivos (arraste com o mouse ou Ctrl + clique).
  4. Confira a ordem com as setas ↑ ↓.
  5. Clique em Juntar e baixar.
A ordem inicial é alfabética com numeração natural — 1, 2, 10 (e não 1, 10, 2). O navegador não informa a ordem em que você clicou nos arquivos, então essa é a regra usada; o botão “Inverter ordem” e as setas corrigem o que for preciso.
PDFs protegidos por senha são marcados em vermelho e ficam de fora do resultado. O pdf-lib não decodifica arquivo criptografado: sem esse aviso eles entrariam como folhas em branco.
