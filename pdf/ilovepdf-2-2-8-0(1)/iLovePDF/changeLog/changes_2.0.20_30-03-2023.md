## iLovePDF Desktop 2.0.20

30/03/2023

<br/>

### New features

- Resize the left navigation panel in the PDF Reader
- It is now possible to swap between tabs with Ctrl+Tab or Ctrl+Shift+Tab

<br/>

### Improvements

- Disable the "New updates" notification.
- Dropdown boxes with multiple options now have scroll bars
- Smoother typing in Watermark text boxes
- Fixed a page number bug that caused issues with single-page documents
- Avatar images load correctly
- Several performance optimization improvements
