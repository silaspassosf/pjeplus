## iLovePDF Desktop 2.1.28

23/07/2025

<br/>

### Improvements

- New Crop PDF tool: With Crop PDF users will be able to crop any selected area to convert that content in a new PDF.
- Show certificate properties: Now user can activate to show certificate properties with the signature element placed on the document
- Add PDF Attachments: Now it is possible to add PDF attachments from the Edit PDF tool.
- Major internal libraries update enhancing compatibility and stability.
- Compare PDF: Many UX improvements done to recently released Compare PDF tool.
- Sign PDF: Fixed an issue that prevented to edit an existing signature drawing.

### macOS

- App notifications: Now macOS system can show notifications when a tool task has finished. 

### Windows

- App notifications: The title name of Windows notifications has been fixed to show the tool name related to the notification.
