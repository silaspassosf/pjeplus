## iLovePDF Desktop 2.1.26

19/06/2025

<br/>

### Improvements

- New Compare PDF tool: Instantly revise text changes with the side-by-side view that automatically highlights edits, or use Content Overlay to view visual edits in images and designs.
- Merge more file types: Merge PDF now lets you combine different file types into a single PDF.
- Name your output file: Choose a custom name before saving your merged document.
- Add signatures to multiple pages: Easily duplicate your signature across multiple pages in the same layout with one step.

### Fixes

- All "Search" feature in the reader has been reviewed to prevent crash situations.
- Several fixes have been applied to ensure that password protected files are successfully processed.
- Fixed a bug in Organize PDF that prevented to successfully drag & drop page elements.
- Several translations in Ukranian have been improved.
- Fixed a processing bug when trying to merge more than 1000 files at once.
- Added a message to warn users about performance affection when working with heavy files.
