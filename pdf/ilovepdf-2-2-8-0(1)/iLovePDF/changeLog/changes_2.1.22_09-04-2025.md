## iLovePDF Desktop 2.1.22

09/04/2025

<br/>

### Improvements

- A new Split by Size feature has been added, allowing users to split their PDFs by size ranges.
- The PDF to Excel tool now includes a selector to choose the result format in either a single or multiple Excel sheets.
- It is now possible to add PDF attachments from the thumbnails sidebar in our Reader.

### For Windows

- Signature validation has been thoroughly reviewed to detect and validate all types of digital signatures.

### For macOS

- Login functionality for macOS has been reviewed to ensure compatibility with all operating system versions.
