## iLovePDF Desktop 2.2.0

08/10/2025

<br/>

### Announcement

- The EXE and DMG installer files will not be available anymore by the end of 2025 and therefore will no longer be supported or updated. If you are a user of one of these versions you'll be notified and encouraged to download official versions from Apple and Microsoft distribution Stores.

### Improvements

- New Redact PDF tool: Redact text and graphics to permanently remove sensitive information from a PDF.
- Compare PDF: Many UX improvements done to recently released Compare PDF tool.
- PDF Reader: The PDF viewer has been fully reviewed with several user experience, PDF compatibility and performance improvements.
- "New" badges in Tools section: From now on, any newly added tool will be highlighted as "New" in the tools section.

### macOS

- Signature detection: Now macOS version of iLovePDF is able to check signature and certificates validation.
