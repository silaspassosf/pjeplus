## iLovePDF Desktop 2.0.180

30/05/2024

<br/>

### Improvements

For macOS: 
- All reader improvements has been tested and adapted for macOS systems. Including:
    - Scroll behaviour has been improved to ease readability.
    - Now reader has better compatibility to open and read much more PDF documents.
    - Zooming rendering has been improved.
    - Several issues affecting app stability and performance have been fixed.
- Added Single Sign On as a new login option.
- Fixed an issue for which the app could crash in Google or Facebook login attemps.

Both platforms:
- Now is possible to select all page text from the right click menu in reader.
- Fixed a bug that prevented Sign PDF to work if arabic language was set.
- Now Premium users will be able to change documents metadata from the reader's left panel.
