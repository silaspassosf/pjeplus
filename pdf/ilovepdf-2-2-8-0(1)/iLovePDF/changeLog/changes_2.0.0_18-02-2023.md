## iLovePDF Desktop 2.0.0

18/02/2023

<br/>

### New features

- New and cleaner UI design with a smoother user experience
- New Home page to easily manage your recent documents
- Fully compatible iLovePDF Desktop for macOS
- Full Arabic localization with Right-To-Left reading UI
- Dark mode available in Settings
- New Tasks history section to check how and when you edited your files
- Save your PDF as plain text with the "Save as Text" option in the "File" menu

<br/>

### Improvements

- Application speed optimized
- New Notifications system in place to inform you about the latest app updates or task results
- Watermark and Page Numbers are compatible with non-latin languages
- Improved compatibility with more file types and filenames
- Option to open and manage document files from local networks
