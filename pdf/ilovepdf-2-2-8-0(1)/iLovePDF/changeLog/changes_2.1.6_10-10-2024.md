## iLovePDF Desktop 2.1.6

10/10/2024

<br/>

### Improvements

- Right-to-Left (RtL) Language Compatibility:
    - Improved accuracy of the "Search" feature with RtL languages.
    - Corrected viewer tab names when filenames are written in RtL.
    - Fixed an issue where scrolling wasn't available in tools for large documents in RtL languages.
    - Resolved a bug that prevented text selection in two-page mode for RtL documents.
    - General stability improvements when working with RtL documents.
- Performance and Optimization:
    - Significant speed improvements, with up to 700% faster processing for the following tools: Office to PDF, Repair PDF, Protect PDF, Compress PDF, and Rotate PDF. Additionally, PDF to Office, Unlock PDF, and Edit PDF tools have been optimized for better performance.
    - Printing dialog has been optimized and several print previews are rendered signinifantly faster now.
- Office to PDF Conversion:
    - Introduced the option to convert using either Online or Offline modes, each utilizing different conversion algorithms. This enhances compatibility with various Office file formats and increases the likelihood of a successful conversion.
