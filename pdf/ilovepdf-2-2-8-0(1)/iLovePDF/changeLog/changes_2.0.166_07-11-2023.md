## iLovePDF Desktop 2.0.166

07/11/2023

<br/>

### New tools (for Windows)

- Sign PDF: You can now e-Sign your PDF documents in a few simple steps.
- Scan to PDF: Scan documents using your mobile device and send them instantly to your iLovePDF Desktop App.
 

<br/>

### Improvements

- Reader and tools: Several improvements that optimize performance.
- Languages: Several fixes and improvements affecting UI and tools in Arabic. 
- Stability and Compatibility: The app is now able to open and process several files that produced errors.
