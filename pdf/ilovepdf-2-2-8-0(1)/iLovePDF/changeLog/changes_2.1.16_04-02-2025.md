## iLovePDF Desktop 2.1.16

04/02/2025

<br/>

### Improvements

- The following tools have been reviewed to improve speed, stability and compatibility with more PDF documents: Sign PDF, PDF to PDF/A, Page numbers, Watermark, Remove pages, Merge PDF, Split PDF, Organize PDF and Office to PDF tools.
- Improved document bookmarks compatibility to avoid reading issues with certain PDF documents.
- Now, thumbnails for Adobe illustrator documents are rendered correctly.
- Corrupted images are now detected before processing them in order to warn users that the process won't be successfull.
- Set password by default won't apply to PDF/A conversion anymore, since PDF/A format do not accept encryption.
- The number of open tabs available has been limited to 30. This doesn't affect the number of files that can be added into a tool.
- A minor UI improvement to improve visibility of scrollbars in RtL languages like arabic.
- Fixed an issue in Edit PDF that was creating a freeze with certain documents when user tried to select texts.

### For Windows
- Users can now rate the app to give satisfaction feedback.
