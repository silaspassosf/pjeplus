## iLovePDF Desktop 2.0.172

05/02/2024

<br/>

### Improvements

- Print. Fixed an issue that prevented files from printing with the proper size in landscape mode.
- Print. "Print quality" option is available again in the print dialogue screen.
- Tools. Fixed a bug that prevented Office to PDF from converting the same file twice.
- Tools. Watermark's Transparency attribute now works with more image types.
- Tools. Organize PDF, Page Numbers and Watermark now allow zoom in thumbnails by using a long click.
- Tools. Fixed a bug in Page Numbers that prevented thumbnails from showing when double-side mode was activated.
- Tools. Improved watermark position in RTL languages.
- Tools. PDF to PDF/A now informs if conversion wasn't possible with the selected compliance level.
- Tools. Improved output filenames with several tools to be more consistent with the tool that users have selected.
- Tools. Watermark PDF now offers the rotation option of -45 degrees.
- Fixed a bug that caused the app window to disappear after disconnecting a screen.
